# 通靈少根筋

2–8 人線上光譜猜題派對遊戲。開房拿到四位數房號，朋友用手機或另一台電腦加入就能一起玩。

## 怎麼玩

1. 開新房間，選角色
2. 把房號傳給朋友
3. 人都到齊後，主持人按開始
4. 每回合一位信眾知道答案藏在光譜哪裡，出一個線索；其他人當通靈者，把指針移到自己覺得該在的位置
5. 越靠近目標越高分（3 / 2 / 1）

推薦面對面或視訊一起玩，這裡沒有內建語音。

## 線上測試

這是有伺服器的網頁遊戲，**GitHub 頁面本身不能開房間**。要跨裝置多人連線，需要部署到 Vercel（或同類平台），並設定 Postgres 的 `DATABASE_URL`（Neon 即可）。沒有資料庫的話，房間狀態無法在不同手機／電腦之間共用。
